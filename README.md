# LSPD Standard Operating Procedures — The Valley RP

Static, responsive SOP reference website for GitHub Pages. No Supabase, database, build step, or server required.

## Deploy
1. Open **Settings → Pages**.
2. Choose **Deploy from a branch**.
3. Select `main` and `/(root)`, then Save.
4. Wait for GitHub Pages to publish.

Expected URL: https://itsthevalleyrp.github.io/LSPD-STANDARD-OPERATING-PROCEDURES/

## Features
- Responsive dark LSPD-inspired layout
- Search across all supplied SOP text
- Section navigation and direct section links
- Local bookmarks and saved-only filter
- Dark/light appearance toggle
- Collapse/expand sections
- Reading progress indicator
- Print-friendly layout
- Keyboard shortcuts: `/` focuses search; `Esc` clears it
